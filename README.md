## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the famous **Titanic dataset**. The goal is to uncover patterns and factors that influenced passenger survival rates during the Titanic disaster.

## 🛠️ Skills & Tools Used
* **Data Cleaning:** Handling missing values (imputation), correcting data types, and removing inconsistencies.
* **Data Manipulation:** Using `Pandas` for grouping, filtering, and feature engineering.
* **Data Visualization:** Utilizing `Seaborn` and `Matplotlib` to create insightful charts (Bar plots, histograms, etc.) with precise labeling using advanced Python techniques like `enumerate`.
* **Feature Engineering:** Creating new features to better understand survival trends.

## 📊 Key Insights
* **Gender:** Females had a much higher survival rate than males.
* **Age & Class:** Analysis shows how age distribution and passenger socio-economic status impacted survival chances.
* **Visualizations:** Custom-made plots with precise statistical annotations.
